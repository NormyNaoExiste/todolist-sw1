Projeto ToDoList criado na aula de Sistemas Web 1

## Tutorial de instalação:
- Clone este repositório
- No terminal, de o comando
    ```cmd:
      npm i
    ```
- Agora ligue o MySQL no [Xampp](https://www.apachefriends.org/pt_br/index.html)
- Volte para o terminal e digite:
  ```cmd:
    npm run dev
  ```
- Teste as rotas com o arquivo de [Rotas](https://github.com/NormyNaoExiste/todolist-sw1/blob/main/backend/rotas.http)
